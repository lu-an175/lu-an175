# 2026-11-05

## xAgent 上下文压缩 + 历史检索（`/compact` + `recallContext`）

新增 `Agent/xAgent/core/context.py`（约 600 行，四块：计量 / 归档 / 检索 / 压缩），全部标准库，不引向量库。

**关键设计（改动前先读这段）**
- 归档：`<cwd>/.agents/context/<YYYYMMDD-HHMMSS>.jsonl`，首行 meta，之后每条消息一行（role/content/tool_calls+参数/tool_call_id/顺序）。写入用 `.tmp` + `os.replace` 原子落盘。**先归档成功才允许压缩**，归档失败直接中止、上下文不动。
- 压缩顺序：`save_archive → build_compaction_messages → provider.chat(msgs, []) → replace_messages`。压缩期间 `provider.chat` **不传 tools**（`OpenAICompatibleProvider` 已改成 tools 为空就不带该字段，有些兼容接口空数组会报错）。
- 替换后的消息结构：`system`（原样保留）+ `user`（摘要 + 归档说明）+ `assistant`（"已理解摘要"）。补 assistant 确认是为了避免连续两条 user 触发某些接口的格式校验。
- 计量：`estimate_tokens` 中文按 1 字 1 token（故意高估）、英文 4 字符 1 token；优先用 API `usage.prompt_tokens + completion_tokens`。`measure_usage()` 是唯一入口。
- 窗口：`MODEL_CONTEXT_WINDOWS` 表 → 前缀匹配 → 128k 兜底并标「默认」；`XAGENT_CONTEXT_WINDOW` 环境变量可覆盖。
- 阈值 0.70（`COMPACT_THRESHOLD`），超了锁输入（仍放行 `/` 命令），压缩成功自动解锁。
- `recallContext` 注册在 `registry.py`（没进 tools.py，tools.py 保持纯文件操作），参数 `text`（必需）/`id`（可选），关键词 AND 不敏感、按命中次数排序、`max_chars` 截断。

**TUI 改动（`tui/app.py`）**
- 新控件 `ContextBanner`（≥70% 才显示，输入框正上方）；StatusBar 最左显示 `上下文 96k/128k 75.0%`，超阈值整行转 warning 色且状态变「等待压缩」。
- 新状态 `_generating`/`_compacting`/`_input_locked`，全部在 `__init__` 初始化（原来 `_messages` 写成类属性，多实例会串数据，已修）。
- `/compact`、`Ctrl+K`；`/clear` 现在**连历史一起清**（否则界面空了、计量还挂在高位）。
- 压缩后必须 `_invalidate_api_usage()`，否则上一次请求的 usage（旧上下文）会立刻重新触发告警。

**MockProvider**：识别到压缩提示词就返回占位摘要，没 Key 也能把 `/compact` 走完。

**验证**：`python -m unittest discover -s xAgent/tests -t .` → 101 个用例，2 个失败是 `TestFetchWeb`（环境缺 trafilatura，改动前就失败）。新增 `tests/test_context.py` 31 个用例全过。

**截图**：`docs/ui-context-warn.png`、`docs/ui-context-compacted.png`（SVG 转 PNG，中文间距偏差是预览字体问题）。
